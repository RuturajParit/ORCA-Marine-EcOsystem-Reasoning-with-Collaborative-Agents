ORCA — Marine Intelligence

Built for SIH 2026 (Agentic AI-powered marine conversational platform). This is a working front-end prototype that demonstrates the core concept with real, live, free data — not mock numbers.

What's real in this build

  • Temperature, Wave height, Wind, Currents — live 3-day forecast from the Open-Meteo Marine & Weather APIs (free, no key, CC BY 4.0), sampled on a grid across the Indian coastline and interpolated into the colour field you see.
  • Temporal resolution: temperature, waves, wind and currents use hourly forecast steps. Salinity, chlorophyll-a, pH, dissolved oxygen and phytoplankton-carbon biomass use the configured Copernicus Marine daily (P1D) products. Those daily values are repeated across the 24 hourly display slots; they are not 24 independent observations. Sea level is requested hourly from Open-Meteo Marine.
  • The time slider scrubs through the actual forecast hours — the colours and wind/current arrows you see when you press Play are real forecasted change over time, not a looping animation.
  • Click anywhere on the sea for an explainable safety check (cites the actual wave height / wind numbers behind the verdict) — a simple, transparent rule engine, not a black box.
  • The "Ask about conditions" box is a small rule-based NL parser (matches a city name + "today / tomorrow") that pulls real numbers and drafts an explainable answer — a stand-in for the LLM-driven conversational agent described in the problem statement.

Extra layers & their sources

Sea level (incl. tides): Open-Meteo Marine, keyless. Salinity, chlorophyll-a, pH, oxygen, phytoplankton biomass: Copernicus Marine global analysis/forecast models (free account; credentials live on the server only). These are model fields at coarse resolution, not the INCOIS PFZ advisory, and "biomass" is phytoplankton carbon, not fish stock. A layer whose source is not reachable stays greyed out with the reason — nothing is invented.

Date

Use the date box beside the timeline to view any day from 60 days back to 7 days ahead (UTC day, shown in IST).

Roadmap to the full SIH solution

Swap the rule-based query box for an LLM agent, add Copernicus Marine WMTS tiles for the remaining parameters, wire in INCOIS's official PFZ advisory and geofencing for the EEZ/IMBL, and support Indian regional-language queries.
